# 冷门食物 · 证据分级

把网红 / 冷门食物按**证据强度**摊开的一个小工具：🟢 比较扎实 / 🟡 有营养但有坑 / 🔴 大头是营销。

每种食物列出：真实好处、坑与风险、被过度营销的说法、剂量·见效、和药物/食物的冲突，以及**可点开的证据出处**（标注一手证据 / 二级参考）。还能按目标（血压、血糖、睡眠…）和谨慎人群（孕妇、抗凝、肾病…）筛选，并按"我的情况"个性化筛查。

> ⚠️ 做着玩的科普小工具，**不替代医生 / 营养师判断**。结论按公开证据的读数写，能核实的标年份 / 类型 / 样本量 / 效应；核不到精确数字的只写结论 + 真实出处，不编。

## 内容原则

- 出处优先 meta 分析 / 系统综述 / 权威机构（NIH、NCCIH、Cochrane、AHA、PubMed、WHO/IARC、FDA）；科普 / 百科作二级参考。
- 全量条目的证据审查记录见 [`EVIDENCE_AUDIT.md`](./EVIDENCE_AUDIT.md)。
